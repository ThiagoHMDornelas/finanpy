## ai-integration-expert

O agente **ai-integration-expert** e um agente documental (arquivo `.md`) que atua como **guia de referencia tecnica e automacao** para futuros agentes de IA no sistema. Ele contem:

- Diretrizes para criacao de agentes com **LangChain 1.0**
- Padroes de integracao com **Django** (settings, models, services, commands)
- Modelos de configuracao e boas praticas para prompts, tools e tratamento de erros
- Instrucoes sobre uso do **Context7 MCP Server** para buscar documentacao atualizada do LangChain
- Exemplo completo de fluxo de criacao de um agente integrado ao Finanpy
- Checklist para validacao de novos agentes

Este agente e consultado sempre que houver necessidade de criar, modificar ou debugar agentes de IA no sistema Finanpy.
